# 🎯 Track My Job

**A complete job application command center — built by a job seeker, for job seekers.**

Track My Job is a full-featured web app for managing a Data Analyst / Business Analyst job search from start to finish — from finding companies, to tracking applications, to prepping for interviews, to comparing offers.

## ✨ Features

### 📋 Core Application Tracker
- Kanban-style pipeline — Saved → Applied → Screening → Interview → Offer → Rejected
- Drag-and-drop cards, full details per application (company, role, salary, location, source, dates, notes)
- Cloud-synced (Supabase) — access your data from any device

### 🔐 Secure Login
- Every user gets their own private, isolated account (email + password)
- Row Level Security ensures no one can ever see another user's data

### 🎯 JD Match Score & Interview Prep
- Paste any job description and instantly see your skill match %
- Highlights matching and missing skills
- Auto-suggests relevant interview questions based on the role
- Recommends practice projects for skill gaps

### ✉️ Message Generator
- One-click drafts for cold outreach, follow-ups, and thank-you notes
- Auto-fills company, role, and recruiter details

### 📄 Resume Version Tracker
- Track which resume version was sent to which company

### ⚖️ Offer Comparison Tool
- Compare multiple offers side-by-side — salary, location, role, and more

### 📊 Insights Dashboard
- Response rate, interview conversion rate, weekly application trends, source breakdown, and stale-application alerts

### 🏢 Company Directory (194+ companies)
- Curated, categorized list — Big IT/MNC, Analytics/Consulting, Product/Tech MNCs, BFSI, Startups, and more
- One-click add or bulk-add entire categories to your tracker
- Built-in shortcuts to LinkedIn, Naukri, Indeed and other job portals — pre-configured to search all analyst roles, sorted by most recent

### 🏢 Company Research Notes
- Keep culture notes, interview experiences, and research per company

### ⬇️ CSV Export
- Export your entire tracker to Excel/Google Sheets anytime
